# Celina 52: Piss Jug Patrol

A 3D arcade truck-stop game built with **PixiJS 8** + **`@pixi/3d`**, **Vite**, and **TypeScript**, featuring the viral **Celina 52 Truck Stop** cast of characters and the towering 8-foot **Piss Jugman**!

## Gameplay
- **3:00 Shift**: Run around the 3D Celina 52 Truck Stop parking lot collecting piss jugs tossed from 18-wheelers and visitors, then cash them in at Colby Kappleman's Urine Jug Exchange counter.
- **Help Piss Jugman Brawl**: Jump in to back up 8-ft Piss Jugman against Dumpster Raccoons, Vagrants, Lot Lizards, and Jerry Petty / Truckers.
- **Truck Stop Chaos**: Watch Lot Lizards hop into parked semi-truck cabs, Tennessee State Troopers roll in to break up trucker fights, Blind Donny cruise through on his forklift, Dennis Herniple fly over in his CEO helicopter, and a weird green Alien UFO beam up jugs with a tractor beam!
- **Scratcher Lotto Counter**: Cash in your shift points at the end of the 3:00 shift for interactive metallic-foil Celina 52 Scratch-Off Lotto Tickets to win cash for upgrades.
- **3D Cast Showcase**: Inspect all 13 custom 3D Celina 52 models on an interactive turntable and listen to their generated character voices.

## Run Locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
